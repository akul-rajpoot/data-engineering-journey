

# Resume Management Strategy

## Objective

Maintain a single Master Resume containing all experience, projects, responsibilities, achievements, and technical skills.

Never apply directly using the Master Resume.

For every job application, create a customized resume aligned with the Job Description (JD) to improve ATS score and increase interview chances.

---

## Resume Structure

### 1. Master Resume

File: `Master_Resume`

Purpose:

- Contains complete professional experience.
- Includes all projects, technologies, responsibilities, achievements, and domain knowledge.
- Acts as the source of truth for all future resumes.
- Updated whenever a new project, technology, certification, or responsibility is added.

Rules:

- Never remove information from the Master Resume.
- Keep all accomplishments documented.
- Update after every major project or job change.

---

### 2. ATS Optimized Resume Versions

Create a separate resume for every important application.

Current Examples:

- Atlassian Resume
- Wayfair Resume

Purpose:

- Tailor keywords to the JD.
- Highlight relevant experience.
- Improve ATS match score.
- Increase recruiter visibility.

---

## Resume Customization Process

For every job application:

### Step 1

Read the Job Description carefully.

Identify:

- Required Skills
- Preferred Skills
- Domain Requirements
- Years of Experience
- Responsibilities
- Technologies Mentioned

---

### Step 2

Compare the JD with the Master Resume.

Map:

- Existing Skills
- Relevant Projects
- Relevant Experience
- Matching Responsibilities

---

### Step 3

Customize the Resume.

Update:

- Professional Summary
- Core Competencies
- Technical Skills
- Project Descriptions
- Experience Bullets

Prioritize keywords from the JD whenever they accurately reflect existing experience.

---

### Step 4

ATS Validation Checklist

Ensure the resume contains:

- Python
- SQL
- PySpark
- Apache Spark
- Databricks
- ETL / ELT
- Data Engineering
- Data Warehousing
- Data Modeling
- Cloud Technologies
- Airflow
- Git
- Domain Specific Keywords from JD

Only include skills that can be confidently discussed during interviews.

---

## Resume Naming Convention

Examples:

- Master_Resume.pdf
- Resume_Atlassian.pdf
- Resume_Wayfair.pdf
- Resume_Deloitte.pdf
- Resume_Mizuho.pdf
- Resume_IRIS.pdf

This makes tracking easier and preserves company-specific optimizations.

---

## Important Rules

1. Master Resume is never sent directly.
2. Every application gets a customized resume.
3. Match resume keywords with JD requirements.
4. Do not add fake experience or skills.
5. Ensure every skill mentioned can be explained in an interview.
6. Keep the Master Resume updated after every project.
7. Maintain separate versions for high-priority companies.

---
