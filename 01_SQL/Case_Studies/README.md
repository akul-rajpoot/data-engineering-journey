# 📊 SQL Case Studies

This folder contains structured SQL case studies designed to simulate real-world data problems and build strong problem-solving skills.

---

## 📁 Folder Structure

Each case study is divided into 3 separate files for clarity and best practices:

### 1️⃣ Tables File
```
01_case_study_tables.sql
02_case_study_tables.sql
03_case_study_tables.sql
```
- Contains:
  - Table creation (DDL)
  - Sample data insertion (DML)
- Purpose:
  - Setup environment for practice
  - Ensure consistent dataset for all users

---

### 2️⃣ Questions File
```
01_case_study_questions.sql
02_case_study_questions.sql
03_case_study_questions.sql
```
- Contains:
  - Only problem statements
- Purpose:
  - Practice SQL without seeing solutions
  - Improve logical thinking and problem-solving

---

### 3️⃣ Solutions File
```
01_case_study_solution.sql
02_case_study_solution.sql
03_case_study_solution.sql
```
- Contains:
  - All SQL solutions
- Purpose:
  - Validate answers
  - Learn optimized and correct approaches

---

## 📌 Case Study Design

Each file includes:
- 2 Case Studies per day
- Real-world scenarios (E-commerce, Banking, etc.)
- Progressive difficulty:
  - Basic
  - Intermediate
  - Advanced

---

## 🧠 Topics Covered

- Joins (INNER, LEFT)
- Aggregations (SUM, COUNT, AVG)
- GROUP BY & HAVING
- Window Functions (ROW_NUMBER, RANK, LAG, LEAD)
- Running Totals & Moving Averages
- CASE WHEN logic
- Subqueries & CTEs

---

## 🎯 Goal

- Build strong SQL fundamentals
- Develop real-world problem-solving ability
- Prepare for Data Engineer / Data Analyst interviews

---

## 🚀 How to Use

1. Run `tables.sql` to create tables and insert data
2. Solve problems from `questions.sql`
3. Compare your answers with `solution.sql`

---

## 🔥 Best Practices Followed

- Clean separation of:
  - Data setup
  - Questions
  - Solutions
- Interview-focused problems
- Scalable and reusable structure
