

# SQL Practice

This folder contains SQL practice questions collected from multiple sources including:

- LeetCode SQL
- StrataScratch SQL
- Interview-style SQL questions
- Custom practice problems

---

## File Structure

### 01_Questions_table_sample_data.sql

Contains:
- Table creation scripts
- Sample data inserts
- Dataset setup required for practice questions

Use this file first to create tables and load sample data.

---

### 02_Questions_only.sql

Contains:
- SQL practice questions only
- No solutions included
- Used for self-practice and interview preparation

Topics covered include:
- Joins
- Aggregations
- Window Functions
- CTEs
- Recursive CTEs
- Ranking Problems
- Business Logic Scenarios

---

### 03_Solution.sql

Contains:
- Solutions for questions from 02_Questions_only.sql
- Multiple approaches where applicable
- Interview-focused SQL patterns and techniques

---

## Practice Workflow

1. Run `01_Questions_table_sample_data.sql`
2. Solve questions from `02_Questions_only.sql`
3. Compare your answers with `03_Solution.sql`
4. Optimize and learn alternative approaches

Build strong SQL skills for:
